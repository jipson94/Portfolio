Comment obtenir la clé GitHub ?
  1. Ouvrez github.com → Nouvelle clé (connecté à votre compte GitHub).
  2. Nom : « Admin site ». Expiration : la plus longue possible.
  3. Repository access : « Only select repositories » → Portfolio.
  4. Permissions → Repository → Contents : Read and write.
  5. « Generate token », puis copiez la clé et collez-la ici.

La clé GitHub est gardée chiffrée chez Cloudflare : vous n'aurez plus à la saisir.
